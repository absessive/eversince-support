## [1.0.1] - 2026-05-15

### Changed

- Replaced the support email placeholder with `contact@absessive.com`.
- Removed future-sensitive monetization claims from support and privacy copy.
- Updated site branding and footer copyright copy.
- Added the EverSince app icon to the site header and browser icon metadata.
- Updated support and privacy copy to match the current app behavior for local
  iPhone storage, reset warnings, Help & About, and custom group fields.

## [1.0.0] - 2026-05-15

### Added

- Added the EverSince support homepage with contact, common task, local-first,
  offline use, and troubleshooting guidance.
- Added the EverSince privacy policy for the first App Store submission.
- Added shared static styling for the support and privacy pages.
- Added README instructions for GitHub Pages publishing and local preview.
